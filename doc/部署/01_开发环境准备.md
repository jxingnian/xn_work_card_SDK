# 开发环境准备

## 1. 支持的开发机

客户开发机必须使用以下一种环境：

- Ubuntu 22.04/24.04 x86_64。
- Windows 11 + WSL2 Ubuntu 22.04/24.04。

SDK 已随附固定 ARM musl 工具链，安装和编译过程不联网下载工具链。客户不得使用 Windows PowerShell、CMD、MinGW、Cygwin 或其他 ARM GCC 直接执行 SDK 的 Linux 脚本。

## 2. Ubuntu 基础命令

Ubuntu 和 WSL2 Ubuntu 至少需要：

- Bash。
- `tar` 和 `gzip`。
- GNU Coreutils，提供 `sha256sum`。
- `file`、`readelf` 和 `nm`。
- CMake 3.14 及以上，仅使用 CMake 构建时需要。

缺少基础命令时，由客户系统管理员在 Ubuntu 中安装：

```bash
sudo apt-get update
sudo apt-get install -y bash tar gzip coreutils file binutils cmake
```

上述 Ubuntu 软件包不包含本项目交叉编译工具链；交叉编译工具链只使用 SDK 随附版本。

## 3. Windows WSL2 进入方法

在 Windows PowerShell 中只执行：

```powershell
wsl
```

进入 WSL 后，提示符会从 `PS C:\...>` 变为类似 `user@host:~$`。从这一刻开始才执行 Linux 命令。

Windows 的 `D:\客户目录\work_card_SDK` 在 WSL 中对应：

```text
/mnt/d/客户目录/work_card_SDK
```

示例：

```bash
cd /mnt/d/客户目录/work_card_SDK
```

`export`、`./scripts/*.sh`、`/mnt/...` 和 `/opt/...` 都是 Linux Bash 内容，不能在 PowerShell 提示符下直接执行。

## 4. 安装随附工具链

在 Ubuntu 或 WSL Bash 的 SDK 根目录执行：

```bash
./scripts/setup_dev_env.sh
```

安装脚本会依次完成：

1. 检查 SDK 随附的工具链归档和独立 SHA-256。
2. 在解压前执行 SHA-256 校验。
3. 将工具链安装到当前 Linux 用户的固定目录。
4. 校验 `arm-linux-musleabi-gcc` 和 `arm-linux-musleabi-strip`。
5. 输出下一步 Demo 编译命令。

默认安装目录为：

```text
$HOME/.local/workcard-toolchain/gcc-20250305-arm-v01c02-linux-musleabi/arm-v01c02-linux-musleabi-gcc
```

该目录位于 Ubuntu/WSL 自身的 Linux 文件系统，不需要 `sudo`。不要手工把工具链解压到 `/mnt/c`、`/mnt/d` 等 Windows 盘符目录，防止 Linux 符号链接和执行权限受损。

重复执行安装脚本是安全的；固定版本已经完整安装时，脚本只报告现有路径，不重复解压。

## 5. 固定工具链版本

正式交付版本固定为：

```text
GCC 10.3.0
GNU Binutils 2.41
musl 1.2.3
Linux 5.10 目标头文件
ARM EABI5 soft-float
```

客户不得从互联网或系统软件源下载其他同名工具链替换随附版本。

## 6. 目标板基线

目标板必须是我方固定固件，满足：

- Hi3516CV610-20S，32 位 ARM EABI5 soft-float。
- `/lib/ld-musl-arm.so.1` 存在。
- 固定 Linux 内核和 rootfs。
- SC2356 Sensor、海思 MPP 和 E-Hal 版本匹配。
- G873-USA1/WS73U WiFi 驱动与固件匹配，且只启用 WiFi。
- 必联 BL-M8723DS1/RTL8723DS 使用固定 `hci_uart.ko`、`rtk_hciattach`、BlueZ、BlueALSA 和 ALSA 插件。
- 固定网络基础组件使用 `/opt/workcard-connectivity`，不得依赖旧 `/opt/lite-p-stream`。
- SysV init 可用。

客户不得在未重新验收的情况下替换内核、musl、`libhal.so`、MPP、Sensor、G873/WS73U WiFi 驱动或 RTL8723DS 蓝牙驱动。

## 7. 编码要求

- 所有源码、配置和文档统一 UTF-8。
- Linux 脚本使用 LF 换行。
- 配置禁止使用 BOM。
- 客户 API 字符串按 UTF-8 处理。
