# 设备信息与能力查询 API

## workcard_sdk_get_device_info

```c
workcard_result_t workcard_sdk_get_device_info(
    workcard_sdk_t *sdk,
    workcard_device_info_t *info);
```

调用前必须将 `info` 清零并填写 `info.struct_size`。返回产品型号、硬件版本、固定固件版本、SDK 版本和 ABI 版本，不返回设备密钥或云端账号。

## workcard_sdk_get_module_capability

```c
workcard_result_t workcard_sdk_get_module_capability(
    workcard_sdk_t *sdk,
    workcard_module_t module,
    workcard_module_capability_t *capability);
```

客户必须根据 `supported` 决定是否调用模块 API。1.0.0 当前状态：

| 模块 | 支持状态 |
| --- | --- |
| DEVICE | 支持 |
| CAMERA | 支持 |
| AUDIO | 支持 |
| WIFI | 支持 |
| BLUETOOTH | 支持经典蓝牙 |
| ETHERNET | 支持 |
| CELLULAR | 不支持 |
| GNSS | 不支持 |
| IMU | 不支持 |

后续硬件的能力由对应固定固件返回，客户不能根据 SDK 版本硬编码支持状态。
