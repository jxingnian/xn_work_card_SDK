# 错误码

| 错误码 | 数值 | 含义 |
| --- | ---: | --- |
| `WORKCARD_OK` | 0 | 操作成功 |
| `WORKCARD_ERROR_INVALID_ARGUMENT` | -1 | 参数、结构长度或范围错误 |
| `WORKCARD_ERROR_NOT_CONNECTED` | -2 | SDK 服务未连接 |
| `WORKCARD_ERROR_NOT_SUPPORTED` | -3 | 当前硬件或固件未实现 |
| `WORKCARD_ERROR_ALREADY_RUNNING` | -4 | 模块已经运行 |
| `WORKCARD_ERROR_NOT_RUNNING` | -5 | 模块尚未运行 |
| `WORKCARD_ERROR_HARDWARE` | -6 | 硬件、驱动或系统命令失败 |
| `WORKCARD_ERROR_IPC` | -7 | 客户库与服务通信失败 |
| `WORKCARD_ERROR_TIMEOUT` | -8 | 同步请求等待超时 |
| `WORKCARD_ERROR_BUSY` | -9 | 资源占用或持久化条目已满 |
| `WORKCARD_ERROR_NO_MEMORY` | -10 | 内存分配失败 |
| `WORKCARD_ERROR_CONFIG` | -11 | 持久化配置损坏或不合法 |
| `WORKCARD_ERROR_PROTOCOL` | -12 | 客户库与服务协议不一致 |
| `WORKCARD_ERROR_INTERNAL` | -13 | 未归类内部错误 |

可使用以下函数取得静态 UTF-8 说明：

```c
const char *workcard_result_string(workcard_result_t result);
```

客户日志应同时记录错误码和模块，但禁止记录密码、设备密钥和完整认证消息。
